## 원고 작업실 · Windows / macOS

[최신 배포 다운로드](https://github.com/careans-official/studio-releases/releases)

윈도우, 애플 실리콘 맥, 인텔 맥에 맞는 ZIP을 한 번 내려받아 실행하세요. 이후 프로그램 안에서 새 버전을 확인하고 설치할 수 있습니다. 사용자 데이터는 각 PC의 홈 폴더 `V2R-Desktop`에 유지됩니다. API 키는 각 OS 보안 저장소에 별도로 보관합니다. 배포에는 사용자 데이터·키·로그인·작업 로그를 넣지 않습니다.

빌드·배포: `v2r-workspace-v`로 시작하는 태그를 올리면 세 운영체제 빌드와 실행 검증을 완료한 뒤 릴리스를 공개합니다. `release_metadata.json`의 버전과 배포 태그를 함께 올립니다. 빌드 소스는 보호된 번들로 관리하며, 공개 저장소에는 원고·계정·키를 올리지 않습니다.

Chrome 확장은 최초 한 번 설치하며, 이후 앱 업데이트 때 작업이 없는 시점에 수정된 확장을 다시 불러옵니다.
